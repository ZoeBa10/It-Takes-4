Εναλλακτικά Χόμπι

Αν θέλεις να μειώσεις τον χρόνο που περνάς μπροστά από τις οθόνες, μπορείς να δοκιμάσεις μερικά εναλλακτικά χόμπι που θα σε βοηθήσουν να χαλαρώσεις και να περάσεις καλά χωρίς την τεχνολογία.

  • Πεζοπορία ή περπάτημα: Βγες στη φύση χωρίς ακουστικά, απλώς για να παρατηρήσεις το περιβάλλον. Διαφορετικά πήγαινε στο κοντινότερο πάρκο για να περπατήσεις ώστε να χαλαρώσεις και να γυμναστείς.
  • Μαγειρική ή ζαχαροπλαστική: Δοκίμασε να φτιάξεις περίπλοκες συνταγές όπως προζυμένιο ψωμί, pizza ή ακόμα και πολύ δύσκολα γλυκά που μόνο επαγγελματίες μπορούν να πετύχουν.
  • Επιτραπέζια παιχνίδια ή παζλ: Τα παζλ οποιασδήποτε δυσκολίας είναι ιδανικά για να "χάνεσαι" για ώρες, με έναν υγιή τρόπο. Τα επιτραπέζια είναι κατάλληλα για μεγάλες παρέες και σε κάνουν να περνάς καλά χωρίς τις οθόνες.
  • Ανάγνωση βιβλίων: Αν δυσκολεύεσαι να συγκεντρωθείς λόγω του κινητού, ξεκίνα να διαβάζεις μικρά διηγήματα ή κόμικς, μιας θεματολογίας που σε ενδιαφέρει. Μόλις εξοικειωθείς μπορείς να διαβάσεις μεγαλύτερα ή και ξενόγλωσσα βιβλία
  • Σχέδιο ή ζωγραφική: Δεν χρειάζεται να είσαι καλλιτέχνης. Μπορείς να ζωγραφίσεις είτε ελεύθερα είτε και με βιβλία ζωγραφικής (coloring books). Ό,τι ταιριάζει στον χαρακτήρα σου!
