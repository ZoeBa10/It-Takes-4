Εναλλακτικά Χόμπι

Αν θέλεις να μειώσεις τον χρόνο που περνάς μπροστά από τις οθόνες, μπορείς να δοκιμάσεις μερικά εναλλακτικά χόμπι που θα σε βοηθήσουν να χαλαρώσεις και να περάσεις καλά χωρίς την τεχνολογία.

  • Πεζοπορία ή περπάτημα: Βγες στη φύση χωρίς ακουστικά, απλώς για να παρατηρήσεις το περιβάλλον. Αλλιώς πήγαινε στο κοντινότερο πάρκο και να κάνεις μερικά χιλιόμετρα περπάτημα ώστε να χαλαρώσεις και να γυμναστείς.
  • Μαγειρική ή ζαχαροπλαστική: Δοκίμασε να φτιάξεις περίπλοκες συνταγές όπως προζυμένιο ψωμί, pizza ή ακόμα και πολύ δύσκολα γλυκά που μόνο επαγγελματίες μπορούν να πετύχουν.
  • Επιτραπέζια παιχνίδια ή παζλ: Τα παζλ των 1000 κομματιών είναι ιδανικά για να "χάνεσαι" για ώρες με έναν υγιή τρόπο. Αλλά και τα επιτραπέζια είναι ιδανικά για να μαζεύουν μεγάλες παρέες και να για να περνάς καλά χωρίς τις οθόνες.
  • Ανάγνωση βιβλίων: Αν δυσκολεύεσαι να συγκεντρωθείς λόγω του κινητού, ξεκίνα με μικρά διηγήματα ή κόμικς. Μόλις εξοικειωθείς μπορείς να αρχίσεις να διαβάζεις και αγγλικά βιβλία ώστε να αναπτύξεις και την αγγλική γλώσσα.
  • Σχέδιο ή ζωγραφική: Δεν χρειάζεται να είσαι καλλιτέχνης,μπορείς να ξεκινήσεις ακόμα και με βιβλία ζωγραφικής για ενήλικες (coloring books). Όταν φτάσεις σε σημείο που θεωρείς πως οι καλλιτεχνικές σου γνώσεις έχουν βελτιωθεί μπορείς να ξεκινήσεις και με ακρυλικά χρώματα.
